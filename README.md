MakeMyTrip – Flight Booking System

About the Project

MakeMyTrip is a flight booking web application developed using React. It provides a user-friendly interface to search flights, view flight details, enter passenger information, and complete a simulated booking process.

Features

* Flight Search and Results
* Flight Details
* Passenger Details
* Seat Selection
* Simulated Payment
* Login and Registration
* My Bookings
* Flight Status

Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* Firebase Authentication
* Cloud Firestore
* Local Storage

Installation and Setup

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal and navigate to the client folder.
4. Run npm install.
5. Run npm run dev.
6. Open the local URL displayed in the terminal.

Note

This is an internship project. The payment process is simulated and does not process real payments.
